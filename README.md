# Nebulah Link

Nebulah Link connects an Xbox 360 console through Xbox 360 Neighborhood on a Windows PC. Its browser interface also works from a phone on the same trusted local network.

**Status: development and hardware trials. No stable release is available yet.** This public repository will hold reviewed, hardware-tested releases. Current development code, tests, trial notes, and internal documentation are kept in a private repository.

When a stable build is ready, download it from [Releases](https://github.com/Nebulah360/Nebulah-Web-App/releases) and verify the published checksum. No console binaries, games, mod menus, or proprietary SDK files will be included.
